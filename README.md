# Site de Referências — Sono e Cognição

Site estático com as seis referências bibliográficas que constam no documento do projeto.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `site-so-referencias` no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Arquivos
- `index.html`: conteúdo das referências.
- `style.css`: identidade visual responsiva.

As referências foram transcritas do PDF enviado. Os links externos levam às páginas de consulta das publicações.
